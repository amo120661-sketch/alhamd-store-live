# ملفات لوحة التحكم — مجلد `a`

هذا المجلد يحتوي على **لوحة إدارة المتجر فقط** (الواجهة الأمامية للأدمن) + الجزء المشترك من السيرفر وقاعدة البيانات اللازم لتشغيلها.

الهوية البصرية مطابقة للموقع الأصلي: الشعار وخط Tajawal والأصفر/الأزرق واسم "حرق اسعار"، مع زر دخول أصفر كما في لوحة التحكم الأصلية.

> ملفات موقع العملاء موجودة في المجلد `s` بجانب هذا المجلد.

## التشغيل
1. انسخ `.env.example` إلى `.env.local` وضع `SUPABASE_DB_URL` و `SESSION_SECRET`.
2. `npm install`
3. `npm run db:setup`
4. للتطوير: `npm run dev` — افتح `http://localhost:3000` (ستظهر لوحة التحكم مباشرة)
5. للنشر: `npm run build` ثم `npm start`

بيانات الدخول: `admin` / `admin123` (يُزرع تلقائياً كحساب `admin@alhamd.local`). غيّرها بعد النشر.

> ملاحظة: كلا المجلدين يتصلان بنفس قاعدة البيانات (Supabase/PostgreSQL)، لذلك تم ترك ملفات السيرفر وقاعدة البيانات في كل نسخة لضمان عملها بشكل مستقل.
