# ملفات الموقع (بوابة المتجر) — مجلد `s`

هذا المجلد يحتوي على **موقع العملاء فقط** (الواجهة الأمامية للمتجر) + الجزء المشترك من السيرفر وقاعدة البيانات اللازم لتشغيله.

الهوية البصرية مطابقة للموقع الأصلي: شعار `images/6b032fc25273f.png`، خط Tajawal، ألوان أصفر `#FED700` / أزرق `#007185`، واسم "حرق اسعار". الخطوط والأيقونات والشعار محفوظة محلياً داخل `public/` فلا تحتاج إنترنت.

> ملفات لوحة التحكم موجودة في المجلد `a` بجانب هذا المجلد.

## التشغيل
1. انسخ `.env.example` إلى `.env.local` وضع `SUPABASE_DB_URL` و `SESSION_SECRET`.
2. `npm install`
3. `npm run db:setup`
4. للتطوير: `npm run dev` — افتح `http://localhost:3000`
5. للنشر: `npm run build` ثم `npm start`

الصفحة الرئيسية هي المتجر. مسار `/admin.html` غير موجود في هذه النسخة (مخصصة للعملاء فقط).
